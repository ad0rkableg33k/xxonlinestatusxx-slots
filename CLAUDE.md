# xXOnlineStatusXx Podcast Site

## Project Overview
Static single-page site hosted on GitHub Pages.
Single HTML file — all CSS and JS are inline/embedded in index.html.
No build step, no dependencies, no package.json.

## Stack
- Vanilla HTML/CSS/JS only
- GitHub Pages (ad0rkableg33k.github.io/[repo-name])
- No frameworks, no npm, no bundler

## Structure
- index.html — the entire site

## Conventions
- Keep everything in index.html unless told otherwise
- Do not introduce npm, node_modules, or build tools
- Do not create separate CSS or JS files unless explicitly asked
- Maintain the existing aesthetic — gothic/punk, dark theme

## Deployment
Push to main branch → auto-deploys via GitHub Pages. No build step needed.
